I'm a Computer Science and Mathematics student at Dartmouth College focused on building AI-powered, full-stack products that solve real problems. At the Geisel School of Medicine, I develop AI platforms for mood-disorder interventions. I previously worked as a Software Engineer at Lenovo and co-founded FoldSpace, an AI-driven spatial-design platform.

I also teach as a CS TA and mentor students in algorithms and data structures. My core work spans Python backends, React and Next.js frontends, machine-learning systems, and cloud deployment.
